Welcome to *EquiSports*, an e-commerce platform where you can browse and purchase sports equipment and accessories.

## Features

- *Responsive Design*: Optimized for mobile, tablet, and desktop.
- *User Authentication*: Sign in using email or Google.
- *Product Management*: Add, view, and manage products.
- *Sorting*: Sort products by price.
- *Dark/Light Mode*: Toggle between light and dark themes.

---

## Setup

1. Clone the repository:
    bash
    git clone https://github.com/your-username/equisports.git
    

2. Install dependencies:
    bash
    cd equisports
    npm install
    

3. Start the application:
    bash
    npm start
    

---

## Tech Stack

- *Frontend*: React, Tailwind CSS
- *Backend*: Node.js, MongoDB
- *Authentication*: Firebase
